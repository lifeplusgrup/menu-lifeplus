# Menu Life+ (flipbook)

Menu digital dengan efek balik halaman. Statis, tanpa server — bisa langsung di-host di GitHub Pages.

## Cara online (GitHub Pages)
1. Buat repo baru di GitHub (public), misalnya `menu-lifeplus`.
2. Upload SEMUA isi folder ini (index.html, folder images, folder lib, .nojekyll) ke repo.
3. Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / `(root)` → Save.
4. Tunggu 1–3 menit, link: https://USERNAME.github.io/menu-lifeplus/

## Ganti isi menu
- Ganti file di `images/` dengan nama yang sama (p01.webp … p26.webp), ukuran ideal 1075×1521 px.
- Kalau jumlah halaman berubah, edit `TOTAL` dan daftar `SECTIONS` di bagian script `index.html`.
